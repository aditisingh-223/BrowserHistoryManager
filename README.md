# 🌐 Browser History Manager

A Java-based console application that simulates the basic functionality of a web browser's history management system using fundamental data structures.

## 📌 Project Overview

The Browser History Manager allows users to visit web pages, navigate backward and forward, view browsing history, and track the number of visits to each website.

It uses Java Collections Framework and file handling to manage and preserve browsing history.

## ✨ Features

- Visit new web pages.
- Navigate to previously visited pages using Back.
- Move forward through browsing history.
- Display complete browsing history.
- Count the number of visits to each website.
- Basic URL validation.
- Save browsing history in a text file.
- Load previously saved history when restarting the application.

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## 📚 Data Structures Used

| Data Structure | Purpose |
|---|---|
| LinkedList | Stores browsing history |
| Stack | Implements Back and Forward navigation |
| HashMap | Stores website visit counts |

## ▶️ How to Run

**Step 1:** Clone the repository.

```bash
git clone https://github.com/aditisingh-223/BrowserHistoryManager.git
```

**Step 2:** Open the project folder.

```bash
cd BrowserHistoryManager
```

**Step 3:** Compile the Java program.

```bash
javac BrowserHistoryManager.java
```

**Step 4:** Run the application.

```bash
java BrowserHistoryManager
```
